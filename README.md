# Практическая работа № 7

WPF-клиент API лекарств. Отдельный проект на .NET 8 с MaterialDesignThemes 5.1.0.

## Запуск

1. Запусти API из шестой практики и проверь список лекарств в Swagger.
2. Открой `pract7.sln` во втором окне Visual Studio. Нужны .NET 8 SDK и компонент разработки классических приложений .NET.
3. Запусти клиент. Введи адрес API из Swagger, например `https://localhost:7001`, без `/swagger/index.html`. Порт должен быть твой.
4. Нажми «Показать». Чтобы вывести весь список, оставь производителя пустым и наличие «Все».

SQL Server и EF Core настраиваются в шестой практике. Здесь используются только HTTP-запросы. При проблеме с сертификатом используй настроенный HTTP-адрес API или выполни `dotnet dev-certs https --trust` на своём компьютере.

## Страницы и код

- `MainWindow` содержит только Frame и открывает MainPage.
- `MainPage` получает список и одну запись через `GetFromJsonAsync`. Фильтры передаются серверу как `manufacturer` и `available`.
- `AddPage` отправляет лекарство через `PostAsJsonAsync`.
- `EditPage` использует `PutAsJsonAsync`, `PatchAsJsonAsync` и `DeleteAsync`.

Все HTTP-вызовы находятся прямо в обработчиках соответствующих страниц, как в примерах лекции. `EnsureSuccessStatusCode` проверяет ответ сервера, а catch показывает ошибку.

`Medicine` описывает ответ API. `MedicineForm` хранит пять полей формы и проверяет ввод. `MedicineData` содержит только изменённые поля для PATCH. Пустые поля этого объекта не включаются в JSON; цена 0 и наличие false включаются.

Список использует ObservableCollection, поэтому изменения видны через Binding без отдельного UpdatePage. Формы привязаны к одному объекту MedicineForm. Прямого присваивания Text или ItemsSource в коде нет.

## Изменение лекарства

Выбери запись и нажми «Открыть». Отредактируй поля:

- «Сохранить всё» отправляет все поля через PUT.
- «Изменить часть» сравнивает форму с открытой записью и отправляет только изменённые поля через PATCH. Дополнительные галочки не нужны.
- «Удалить» требует подтверждения.

После успешной операции обновляется список и открывается каталог. Есть проверки названия, производителя, цены, даты, выбранной записи и отсутствия изменений. Повторное нажатие кнопок во время запроса игнорируется. Если ответ не пришёл или возникла ошибка, сначала проверь список: сервер мог успеть сохранить изменение.

# Практическая работа № 7

Отдельный WPF-клиент для API лекарств из практической работы № 6. .NET 8, MaterialDesignThemes 5.1.0.

## Запуск

1. Запусти API из шестой работы. Убедись, что GET `/api/v1/Medicines` работает в Swagger.
2. Открой `pract7.sln` во втором окне Visual Studio и запусти проект. Нужны .NET 8 SDK и компонент «Разработка классических приложений .NET».
3. Введи адрес API, например `https://localhost:7001`. Используй свой порт из Swagger, без `/swagger/index.html`.
4. Нажми «Показать». Оставь производителя пустым и наличие «Все», чтобы получить весь список.

Подключение к SQL Server настраивается только в проекте API. Если HTTPS не работает из-за сертификата, используй настроенный HTTP-адрес API или доверь сертификату командой `dotnet dev-certs https --trust` на своём компьютере.

## Работа с программой

- «Добавить» открывает отдельную форму нового лекарства.
- Выбери строку и нажми «Открыть»: программа получает лекарство по Id.
- «Сохранить всё» отправляет все поля через PUT.
- «Изменить выбранное» отправляет через PATCH только отмеченные поля. Для изменения наличия отметь «Изменить наличие (PATCH)», затем укажи само наличие второй галочкой.
- «Удалить» удаляет запись после подтверждения.
- «Назад» возвращает каталог. После изменения данные обновляются с сервера.

Фильтры передаются в API как `manufacturer` и `available`. Сервер должен поддерживать эти параметры. PATCH принимает обычный JSON-объект с необязательными полями.

## Где находится код

`MainWindow` содержит только Frame и открывает `MainPage` через `MainFrame.Navigate`.

`MainPage.xaml.cs` содержит свойства для Binding и методы:

- `Send` — отправляет HTTP-запрос, проверяет ответ и ошибки подключения.
- `LoadList` — получает список с выбранными фильтрами.
- `LoadRecord` — получает одну запись и заполняет свойства формы.
- `ReadForm` — проверяет поля и собирает данные для отправки.
- `Create_Click`, `Put_Click`, `Patch_Click`, `Delete_Click` — выполняют соответствующие операции.
- `UpdatePage` — сообщает привязкам, что значения изменились.

`AddPage` и `EditPage` содержат формы и вызывают нужные методы главной страницы. `Medicine` описывает ответ API. `MedicineData` описывает отправляемые поля: значения null не отправляются, поэтому PATCH не меняет неотмеченные поля. Ноль и false при этом отправляются.

Есть проверки пустых полей, длины текста, цены, даты, выбранной записи и выбранных полей для PATCH. Ошибки показываются в MessageBox. Во время запроса кнопки отключаются. После тайм-аута сначала нажми «Показать»: сервер мог сохранить изменение, даже если ответ не дошёл.
